# App Icon Assets

## Required Files

### app_icon.png (1024x1024)
- Full app icon with background
- Dark background (#141414) with the iFlixify logo
- Used for: Google Play Store listing, legacy Android icon

### app_icon_foreground.png (432x432 for adaptive icon)
- Foreground layer only (transparent background)
- The iFlixify logo/text centered in a 66% safe zone (72dp from center)
- Used for: Android adaptive icon foreground

### splash_logo.png (512x512)
- App logo on transparent background
- Centered on the dark splash screen
- Used for: Splash screen

## Design Guidelines
- Background color: #141414 (near-black)
- Accent color: #E11D48 (red)
- Text: White or accent
- Style: Netflix-inspired, bold, minimal
